# Exploratory-customer_behavior_analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across different product categories. The objective is to identify spending patterns, customer segments, product preferences, subscription trends, and discount behavior to generate actionable business insights.

## 🛠️ Tools & Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- Jupyter Notebook

## 📊 Dataset

- 3,900 rows
- Customer demographics
- Purchase details
- Shopping behavior
- Subscription status
- Discount and promotional information
- Review ratings
- Shipping information

## 🔍 Project Workflow

### 1. Data Cleaning & Preparation – Python

Used Python and Pandas to:

- Load and explore the dataset
- Check data structure and summary statistics
- Handle missing values
- Standardize column names
- Create age groups
- Create purchase frequency features
- Check data consistency and remove redundant columns

### 2. SQL Analysis – PostgreSQL

Loaded the cleaned dataset into PostgreSQL and answered key business questions, including:

- Revenue generated by gender
- High-spending customers using discounts
- Top-rated products
- Standard vs. Express shipping performance
- Subscribers vs. non-subscribers
- Products with the highest percentage of discounted purchases
- Customer segmentation
- Top 3 products within each category
- Repeat buyers and subscription behavior
- Revenue contribution by age group

### 3. Power BI Dashboard

Created an interactive Power BI dashboard to visualize customer behavior and present key business insights.
![Customer Behavior Dashboard](Screenshot%202026-09-01%20215027.png)

## 💡 Key Business Recommendations

- Promote exclusive benefits to increase subscriptions
- Introduce loyalty programs for repeat customers
- Review discount strategies to balance sales and margins
- Promote top-rated and best-selling products
- Target high-revenue customer age groups
- Analyze express-shipping customers for targeted marketing
